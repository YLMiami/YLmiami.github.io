Recipe Retrieval Assistant

From a web crawler to question answering over recipes

Yunfei Liang · team project

[GitHub](team repository, private)

TL;DR: A crawler collects recipe pages. Their text is embedded and stored in Postgres with pgvector. A command-line prompt retrieves the closest recipes for a question and has a language model answer from them.

Crawlercollects recipe pages
→
Postgres + pgvectorstores text and embeddings, runs in Docker
→
Retrievernearest recipes for the question
→
Language modelanswers from the retrieved recipes
→
Command-line promptinteractive session
