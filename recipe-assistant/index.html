Recipe Retrieval Assistant

From a focused web crawler to grounded answers about recipes

Anna Dvořáková, Srećko Krečković, Yunfei Liang · Web Information Extraction and Retrieval, University of Ljubljana, 2026

[GitHub](team repository, private)

TL;DR: A crawler collects dessert recipes, each recipe is split into typed segments and embedded into Postgres with pgvector, and a local language model answers questions from the one recipe that retrieval and reranking select. Every query is also answered without retrieval, so the effect of the context is visible.

Pipeline

Preferential crawlerfrontier ranked by dessert keywords, robots.txt cache, duplicate check
→
Extractiontitle, summary, ingredients, instructions, nutrition
→
Postgres + pgvectorall-MiniLM-L6-v2 embeddings, in Docker
→
Retrieve and reranktop 5 by cosine, reordered by a cross-encoder
→
AnswerLlama 3.2 through Ollama, given the full recipe

Design decisions

  • Search short segments, answer from the whole recipe. Titles, summaries, ingredient lists and nutrition lines are embedded separately. All are under 1,000 characters, so nothing needs chunking. Once the best segment is found, every segment of that recipe, including the instructions, goes to the language model.
  • Two-stage ranking. Vector search returns five candidates and a cross-encoder that reads the query and the segment together reorders them. For "Which cake can be baked using chocolate, butter and eggs?" the two stages disagree on the top result.
  • Everything local. The embedding model, the reranker and the language model all run on a laptop. The database and its admin console start with one docker compose up.
  • A no-retrieval control. Each question is answered twice, with and without the retrieved recipe.

One query, both modes

Query      : Any no bake chocolate dessert recipe?
Retrieved  : No-Bake Chocolate Delight  (similarity: 0.7926)

  [INGREDIENTS]
  prepared graham cracker crust, chopped pecans,
  instant chocolate pudding mix, frozen whipped topping, thawed
  [NUTRI]
  338 Calories, 21g Fat, 37g Carbs, 3g Protein

From the saved demo output. With this context the model describes the retrieved recipe. Without it, the model writes out a different recipe from memory.

Where it fails

  • Questions across many recipes. "Which recipe has the fewest calories?" needs a comparison over the corpus. The system retrieves one recipe and can only describe that one.
  • Questions the recipes do not answer. "How do I fix a cake that sank in the middle?" is general baking knowledge. The model alone does better than the model tied to one recipe.
  • No scored evaluation yet. The test set is ten queries, six expected to work and four expected to fail, judged by reading the answers. A recall number over a labelled question set is the next step.
